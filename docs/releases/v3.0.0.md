Translator 3.0 rebuilds the core around typed, versioned sources and a storage interface. The translator and catalogue builder delegate data access to those interfaces; compiled PHP storage is included in the core package.

This is a breaking release requiring PHP 8.4+ and the tokenizer extension. Upgrade the Nette adapter to 3.0 together with the core. See the [migration guide](https://github.com/bckp/translator-core/blob/v3.0.0/MIGRATION.md) for the removed 2.x file, event and array APIs.

- Every source provides a mandatory opaque string version. Production checks versions with a configurable probability, defaulting to 1% at catalogue initialization; debug checks every initialization. Individual translations never load a source or verify its version.
- `Catalogue::get($key, $number = null): ?string` resolves plural forms internally. Input loaders return `MessageCatalogue` with strings or immutable `PluralMessage` objects.
- `forceRecompile()` rebuilds even with identical versions; `replaceCatalogue()` updates a live translator using the same locale.
- PHP catalogues return ordinary text from generated `match` expressions and embed the selected plural rule directly from `PluralProvider`. Cache publication uses atomic replacement.
- Production catalogue lookups avoid diagnostics checks. An optional diagnostic wrapper reports unknown keys and missing forms.
- Empty strings and `"0"` remain valid translations. Plural fallback priority is deterministic. Invalid formatting throws `TranslatorException` with the original `ValueError` attached.
- NEON parsing is available through the standalone `bckp/translator-neon` source; Nette, Latte and Tracy integration is provided by `bckp/translator-nette` 3.0.

Local warm-cache comparisons with v2 measured Czech plural translation about 20–25% faster and formatted strings about 11–15% faster for a 1,000-entry catalogue on PHP 8.4 and 8.5. Generated catalogues use more OPcache memory. See the [benchmark methodology and results](https://github.com/bckp/translator-core/blob/v3.0.0/benchmarks/README.md) for the limits of those measurements.

Validation: Nette Tester on PHP 8.4 and 8.5, PHPStan level 8, PER Coding Style 3 with tabs, Composer validation and audit, OPcache and cache-concurrency checks, API compatibility tooling, and clean production installs without development dependencies.
